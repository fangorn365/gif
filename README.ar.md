محرر GIF في ملف HTML واحد. كل شيء يعمل محليًا داخل متصفحك: بدون رفع ملفات، وبدون حساب، وبدون ملفات تعريف ارتباط.

## البدء السريع
1. افتح `OrcaGif.html` في متصفحك.
2. **حمّل** ملف GIF أو صورة أو فيديو (ملف، رابط، أو سحب وإفلات).
3. عدّل وأضف الطبقات، ثم اضغط **إنشاء GIF** ونزّل النتيجة.

## التحرير
- **إطار البداية**، **إطار النهاية**، **السرعة**، **عكس**، **FPS** (الحد الأقصى 50)، **عرض الإخراج**، **اقتصاص**.
- **خلفية شفافة**، **التمويه (Dithering)**، **علامة مائية** (مفعّلة افتراضيًا – يرجى إبقاؤها مفعّلة لدعم هذه الأداة المجانية).

## الطبقات
- **+ نص**، **+ صورة**، **✏️ رسم**.
- اسحب الطبقة داخل الصورة. عجلة الفأرة = الحجم، Shift + العجلة = التدوير.
- يمكن سحب الطبقات خارج الصورة (هامش معتم) وإرجاعها لاحقًا.

## الحركة
1. فعّل **تحريك (إطارات رئيسية)**.
2. انتقل إلى إطار آخر واسحب الطبقة: يُنشأ إطار رئيسي وتُحسب الإطارات بينهما بسلاسة.
3. اختر تسارعًا أو قالبًا جاهزًا: ظهور تدريجي، طيران للداخل، نبض، اهتزاز، دوران، ارتداد.

## المشاريع
- **حفظ** يخزّن المشروع في المتصفح.
- **ملف المشروع ↓ / ↑** يصدّر / يستورد ملفًا حقيقيًا (`.gifproj`).

## الاختصارات
`Ctrl+Z` تراجع · `Ctrl+Y` إعادة · `Ctrl+S` حفظ · `Ctrl+D` تكرار الطبقة · `←` `→` الإطار السابق / التالي
