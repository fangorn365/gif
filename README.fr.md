# OrcaGif – Éditeur de GIF gratuit et privé

Un éditeur de GIF dans un seul fichier HTML. Tout fonctionne en local dans votre navigateur : pas d'envoi de fichiers, pas de compte, pas de cookies.

## Démarrage rapide
1. Ouvrez `OrcaGif.html` dans votre navigateur.
2. **Chargez** un GIF, une image ou une vidéo (fichier, URL ou glisser-déposer).
3. Modifiez, ajoutez des calques, cliquez sur **Générer le GIF** et téléchargez le résultat.

## Modifier
- **Image de début**, **Image de fin**, **Vitesse**, **Inverser**, **FPS** (50 max.), **Largeur de sortie**, **Recadrer**.
- **Arrière-plan transparent**, **Tramage (dithering)**, **Filigrane** (activé par défaut – merci de le laisser activé pour soutenir cet outil gratuit).

## Calques
- **+ Texte**, **+ Image**, **✏️ Dessiner**.
- Faites glisser un calque dans l'image. Molette = taille, Maj + molette = rotation.
- Les calques peuvent être déplacés hors de l'image (marge assombrie) et ramenés plus tard.

## Animation
1. Cochez **Animer (images clés)**.
2. Allez à une autre image et faites glisser le calque : une image clé est créée et les images intermédiaires sont interpolées.
3. Choisissez une accélération ou un préréglage : Fondu entrant, Entrée en volant, Pulsation, Tremblement, Tourner, Rebondir.

## Projets
- **Enregistrer** sauvegarde le projet dans le navigateur.
- **Fichier projet ↓ / ↑** exporte / importe un vrai fichier (`.gifproj`).

## Raccourcis
`Ctrl+Z` annuler · `Ctrl+Y` rétablir · `Ctrl+S` enregistrer · `Ctrl+D` dupliquer le calque · `←` `→` image précédente / suivante
