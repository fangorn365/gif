# OrcaGif – Free & Private GIF Editor

A GIF editor in a single HTML file. Everything runs locally in your browser: no upload, no account, no cookies.

## Quick start
1. Open `OrcaGif.html` in your browser.
2. **Load** a GIF, image or video (file, URL or drag & drop).
3. Edit, add layers, click **Generate GIF** and download the result.

## Edit
- **Start frame**, **End frame**, **Speed**, **Reverse**, **FPS** (max. 50), **Output width**, **Crop**.
- **Transparent background**, **Dithering**, **Watermark** (on by default – please keep it on to support this free tool).

## Layers
- **+ Text**, **+ Image**, **✏️ Draw**.
- Drag a layer in the image. Mouse wheel = size, Shift + wheel = rotation.
- Layers can be dragged outside the image (dimmed margin) and brought back later.

## Animation
1. Tick **Animate (keyframes)**.
2. Go to another frame and drag the layer: a keyframe is created and the frames in between are interpolated.
3. Pick an easing or a preset: Fade in, Fly in, Pulse, Wiggle, Spin, Bounce.

## Projects
- **Save** stores the project in your browser.
- **Project file ↓ / ↑** exports / imports a real file (`.gifproj`).

## Shortcuts
`Ctrl+Z` undo · `Ctrl+Y` redo · `Ctrl+S` save · `Ctrl+D` duplicate layer · `←` `→` previous / next frame
