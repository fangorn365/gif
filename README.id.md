# OrcaGif – Editor GIF Gratis & Privat

Editor GIF dalam satu file HTML. Semuanya berjalan lokal di browser Anda: tanpa unggah, tanpa akun, tanpa cookie.

## Mulai cepat
1. Buka `OrcaGif.html` di browser Anda.
2. **Muat** GIF, gambar, atau video (file, URL, atau seret & lepas).
3. Edit, tambahkan lapisan, klik **Buat GIF**, lalu unduh hasilnya.

## Edit
- **Bingkai awal**, **Bingkai akhir**, **Kecepatan**, **Balik**, **FPS** (maks. 50), **Lebar keluaran**, **Pangkas**.
- **Latar belakang transparan**, **Dithering**, **Watermark** (aktif secara default – mohon biarkan tetap aktif untuk mendukung alat gratis ini).

## Lapisan
- **+ Teks**, **+ Gambar**, **✏️ Gambar tangan**.
- Seret lapisan di gambar. Roda mouse = ukuran, Shift + roda = rotasi.
- Lapisan bisa diseret ke luar gambar (tepi digelapkan) dan dikembalikan nanti.

## Animasi
1. Centang **Animasikan (keyframe)**.
2. Pindah ke bingkai lain lalu seret lapisan: keyframe dibuat dan bingkai di antaranya diinterpolasi.
3. Pilih easing atau preset: Muncul perlahan, Terbang masuk, Berdenyut, Bergoyang, Putar, Memantul.

## Proyek
- **Simpan** menyimpan proyek di browser.
- **File proyek ↓ / ↑** mengekspor / mengimpor file asli (`.gifproj`).

## Pintasan
`Ctrl+Z` urungkan · `Ctrl+Y` ulangi · `Ctrl+S` simpan · `Ctrl+D` duplikat lapisan · `←` `→` bingkai sebelumnya / berikutnya
