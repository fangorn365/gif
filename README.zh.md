# OrcaGif – 免费且注重隐私的 GIF 编辑器

[English](README.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · **中文** · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Bahasa Indonesia](README.id.md)

只有一个 HTML 文件的 GIF 编辑器。一切都在浏览器本地运行：无需上传、无需账号、无 Cookie。

## 快速开始
1. 在浏览器中打开 `OrcaGif.html`。
2. **加载** GIF、图片或视频（文件、URL 或拖放）。
3. 编辑、添加图层，点击**生成 GIF** 并下载结果。

## 编辑
- **起始帧**、**结束帧**、**速度**、**倒放**、**FPS**（最大 50）、**输出宽度**、**裁剪**。
- **透明背景**、**抖动（Dithering）**、**水印**（默认开启，请保持开启以支持这款免费工具）。

## 图层
- **+ 文字**、**+ 图片**、**✏️ 绘制**。
- 在画面中拖动图层。鼠标滚轮 = 缩放，Shift + 滚轮 = 旋转。
- 图层可以拖到画面之外（变暗的边缘区域），之后再拖回来。

## 动画
1. 勾选**启用动画（关键帧）**。
2. 切换到另一帧并拖动图层：会自动创建关键帧，中间的帧会被平滑插值。
3. 选择缓动或预设：淡入、飞入、脉冲、摇晃、旋转、弹跳。

## 项目
- **保存**会把项目存放在浏览器中。
- **项目文件 ↓ / ↑** 导出 / 导入真实文件（`.gifproj`）。

## 快捷键
`Ctrl+Z` 撤销 · `Ctrl+Y` 重做 · `Ctrl+S` 保存 · `Ctrl+D` 复制图层 · `←` `→` 上一帧 / 下一帧
